# GitHub 私有仓库与提交基线

## 仓库

- 地址：https://github.com/shulinw27-web/yuanyu-zhinao
- 默认分支：`main`。
- 首次导入前已通过 GitHub API 确认 `private=true`、仓库为空；本地 Git 已具备推送权限。
- 导入的是当前开发快照，不是生产发布或已完成全部验收的版本。

## 上传范围

包含各端源码、测试、依赖锁文件、配置模板、部署脚本和 `docs/` 项目文档。
不包含依赖安装目录、模型权重、Python 虚拟环境、编译产物、运行数据库、会话记录、临时材料与 `output/` 生成结果。
`.env`、`ark.json`、本地 JSON 配置、私钥和证书容器已加入忽略规则。真实密钥仍须保存在仓库之外；私有仓库也不是密钥存储服务。

首次上传不包含个人资料或与产品无关的文件。项目说明书中的演练数据属于项目示例，不能作为企业生产事实使用。

## 后续提交

```powershell
git status
git diff
npm run security:source-scan
git add <本次确认要提交的文件或目录>
git diff --cached --stat
git commit -m "描述本次修改"
git push
```

提交前检查新增文件，尤其是附件、日志、配置和导出结果。不要使用强制添加将被忽略的凭据或运行数据带入仓库；不要用强制推送覆盖他人的提交。首次提交使用 GitHub 的 noreply 作者邮箱，不上传本机占位邮箱。

仓库内已有 GitHub Actions 配置，推送可能触发质量与安全检查。远程 CI 状态应以实际运行结果为准；私有仓库的部分安全功能可能需要另行开通，本次不购买服务或变更账号权限。
