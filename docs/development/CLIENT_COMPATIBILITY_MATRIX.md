# 元域智脑客户端兼容与发布矩阵

> 版本：v1.0　更新日期：2026-09-01

## 1. 客户端版本策略

| 客户端 | 当前协议标识 | 最低版本基线 | 生产发布要求 |
|---|---|---|---|
| 管理 Web/业务 Web | `web` | 0.1.0 | 同源部署、CSP/HSTS、企业 SSO |
| 业务 Desktop | `desktop` | 0.3.0 | Windows 签名、更新清单签名、企业分发 |
| Mobile | `mobile` | 0.3.0 | 企业签名、MDM/MAM、设备合规 |
| 钉钉手机 H5 | `dingtalk-mobile` | 0.3.0 | 企业内部微应用、HTTPS、成员绑定和真机免登验收 |
| 钉钉 PC H5 | `dingtalk-pc` | 0.3.0 | 同一 H5 站点，不能使用 Electron 本机桥接 |
| 元域智营 Web | `semantic-web` | 0.2.0 | 元域智营角色、发布门禁 |
| 元域智营 Desktop | `semantic-desktop` | 0.2.0 | 签名包、受信导航、元域智营角色 |

客户端通过 `x-client-platform` 与 `x-client-version` 声明协议版本。生产环境中缺失标识或低于最低版本返回 HTTP 426，并可从 `/api/platform/client-policy` 获取兼容策略。版本升级应先发布兼容服务端，再灰度客户端；回滚服务端前必须确认当前客户端仍受上一版本支持。

## 2. 主流视口验证矩阵

| 视口 | 代表场景 | 核心验收 |
|---:|---|---|
| 360×800 | 小屏手机 | 对话、确认卡、附件、底部输入无遮挡 |
| 768×1024 | 平板竖屏 | 导航可收起，表单与语义图可操作 |
| 1024×768 | 平板横屏/旧办公屏 | 不出现关键按钮越界 |
| 1280×720 | 小型笔记本 | 对话输入固定且内容区独立滚动 |
| 1366×768 | 常见办公笔记本 | 主工作台、侧栏、任务切换完整 |
| 1440×900 | 高密度办公屏 | 字号、间距和信息密度均衡 |
| 1920×1080 | 标准桌面 | 三栏布局不被过度拉伸 |
| 2560×1440 | 2K | 内容最大宽度、图谱缩放与浮层定位 |
| 3840×2160 | 4K/缩放 | 125%/150%/200% 系统缩放下清晰可用 |

## 3. 弱网与恢复

共享客户端运行时只自动重试安全读请求（GET/HEAD/OPTIONS）；写操作除非带幂等键并由调用方显式允许，否则不自动重试。验收需要覆盖离线、100–500 ms 延迟、1%–5% 丢包、429、502/503/504、切换网络、休眠恢复和应用重启。

必须保持：用户输入不丢失；任务状态从服务端恢复；未知写结果显示“待核实”而不是“失败”或“完成”；撤权后缓存立即失效；同一任务在 Web、Desktop、Mobile 中的业务编号、审批状态和证据链一致。

## 4. 无障碍与交互

- 键盘可到达导航、任务列表、对话、确认卡、模型校对和版本回滚；焦点顺序与视觉顺序一致。
- 状态不能仅依赖颜色，错误与拦截提供可读原因；关键变化通过 ARIA live 区域通知。
- 支持 200% 文本缩放、减少动画、高对比模式和屏幕阅读器基础语义。
- 对话输入区固定在工作区底部，但不得遮挡最后一条消息；内容区独立滚动并保留任务切换位置。
- 多模态附件显示类型、大小、扫描状态、保留期和删除入口。

## 5. 回归门禁

提交至少通过 `npm run test:clients`、`npm run build`、`npm run build:mobile` 和 `npm run build:desktop`。正式发布还需在真实签名包、企业代理、受控浏览器、MDM/MAM 设备和上述视口矩阵中验收。
