# 身份源适配回归报告

日期：2026-09-08。范围：统一身份适配器、钉钉兼容、OIDC、IAM 边界及智脑/元域智营 SDK。测试使用本地生成的 RSA 密钥和合成令牌，没有使用企业密钥或访问真实企业目录。

## 本次修改

- 从统一会话服务中移除钉钉专属配置判断，改为调用身份适配器验证绑定。
- 增加托管身份源清单、多个 OIDC issuer 的精确选择、不可变 subject 绑定、可选外部企业声明校验。
- 托管模式关闭 Mock 登录和 Demo header；未注册、停用、错误配置、未绑定用户均拒绝认证，不自动回退。
- 智脑及元域智营 SDK 增加身份源选择和缓存隔离，共享登录界面由宿主提供身份源名称。
- 修正 CORS 对 Authorization 和身份源选择头的支持；账号中心只展示已实现适配器，不将未实现的 LDAP/企业微信能力展示成待配置接入。

完整测试输出位于 `output/identity-provider-regression-20260908.log`。计数为各测试命令汇总；部分安全测试会在不同回归套件中重复执行，不等于 377 个互不重复的业务场景。

重点验证：标准 OIDC 不要求非标准 tid；同 subject 跨 issuer 不混用；错误 audience、签名、企业声明被拒绝；外部管理员角色不提升 IAM 权限；撤销绑定和平台权限版本变化使会话失效；未配置默认身份源不自动选取；旧本地会话不能伪装成企业登录；配置文件异常不降级；两端令牌获取失败不发送匿名替代请求。

## 未覆盖与上线条件

本轮没有真实企业 SSO、钉钉手机/PC 真机、外部目录组织同步或全局注销验收，也没有新增页面的浏览器视觉专项。构建通过不能代替真机验收。浏览器授权码、PKCE 和刷新令牌由企业宿主提供，其他平台专用协议仍须独立开发。

这次没有替用户创建真实绑定或切换运行中 API 的认证配置，现有演示入口保留。接入企业环境前，按 [身份源适配指南](../guides/IDENTITY_PROVIDER_ADAPTERS.md) 准备可信发行方、应用 audience、绑定表及分角色测试账号，并完成现有生产门禁。
