# Ontology Playground 融合实施与回归记录

日期：2026-10-09。以下先保留首轮记录，续轮完成结果见末尾。最终范围以[融合清单](../architecture/ONTOLOGY_PLAYGROUND_INTEGRATION_PLAN.md)为准。

## 已实施

共享 `OntologyGraph` 与纯数据适配器不改变模型所有权。模型总览、待审核任务、候选编辑器复用同一组件，支持筛选、邻居、缩放、拖动、详情和有向路径。已删除对象/关系不参与路径计算；过滤隐藏节点后清空详情。未保存编辑不显示旧差异。替换提案补齐被删除关系，合并提案不伪造删除。

知识领域新增关联列表、确认保存、按修订撤回三个接口，仅语义资料端暴露。关联必须引用服务端复验的原文与当前模型指纹；写入事务重新检查指纹，不接受客户端租户或主体覆盖。读取再次检查权限、引用和模型；失效关联不返回摘录。关联按租户、主体、角色隔离，历史记录不物理删除。

回归时修复原有路由漏洞：禁止的整模型删除与明确否定指令不再被宽泛修订规则或模型意图覆盖。发布前校验与模拟构建门禁保留；相应旧用例更新为断言正确拒绝，而非授权发布。

## 操作路径

1. 模型校对页查看“语义模型关系图”；筛选或点击对象/关系。
2. Agent 工作台打开待审核任务，在任务图中核对差异。候选编辑器仍提供字段及映射修改。
3. 知识资料先检索片段，再建立人工关联；记录中可重新核验原文或撤回。
