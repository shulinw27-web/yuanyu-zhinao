## 浏览器检查

使用 Playwright 在独立浏览器会话中检查。普通浏览器打开真实入口时显示“从钉钉进入”，没有账号密码或模拟登录入口。已验证登录后的前端链路使用合成 SDK 和拦截的 API 返回值，所有业务回复都明确标注为合成结果，没有调用真实模型、企业接口或读取用户文件。

视口覆盖 360×800、390×844、390×450、768×1024、1024×768、1366×768、1920×1080。390×450 用于模拟键盘占用后的短视口，不代表真实 iOS/Android 输入法行为已验收。

检查输入框和发送按钮在可见范围内、移动导航不遮挡发送、页面无横向溢出、钉钉入口不出现 Electron 桥接工具。合成登录码通过 POST 提交，登录前不带旧身份或 Demo 角色，后续消息请求携带平台会话。测试会话没有页面运行错误。

验证过程中发现并处理：

- 短屏欢迎区占用对话空间：短视口收起欢迎与快捷区，使用 Visual Viewport 高度约束工作台。
- 手机输入字号较小时可能触发输入放大：钉钉入口输入控件使用 16px，并为双行输入保留高度。
- 紧凑 PC 顶部按钮换行：固定工具组收缩策略。
- 原生产入口强制 OIDC：新增有效钉钉身份源选项，同时保留非 Mock、来源、单节点与 KMS 等门禁。
- 原会话未关联钉钉成员绑定：会话保存企业、应用与 userid 绑定；后续请求核验绑定是否仍有效。
- 登录服务网络请求可能长时间等待：补充配置/挑战及登录请求超时，免登码提交不自动重试。

浏览器复核脚本与截图位于 [验证目录](../../output/playwright/dingtalk/)，包括 `browser-qa.js` 与 `workbench-*.png`。脚本只适用于隔离的合成验收，不得把 SDK 替身或合成账号加入生产应用。

## 尚未验收的外部条件

- 企业应用创建、可见范围、域名和网络出口配置，以及官方免登码的真实交换。
- Android/iOS/Windows/macOS 钉钉客户端真机登录、选文件、键盘、代理和重新打开应用。
- 钉钉侧离职/切换企业等事件的自动同步；目前需停用平台账号或删除映射，并重新打开应用刷新宿主身份。
- 多 API 副本共享挑战存储、企业生产身份/数据域联调。
- 钉钉工作通知、钉盘、扫码、原生录音和钉钉审批。这些不在本期代码接入范围内。

配置与上线前检查见 [钉钉接入指南](../guides/DINGTALK_INTEGRATION.md)。
