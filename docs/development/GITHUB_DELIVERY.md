# GitHub提交与交付约定

本项目后续每次上传GitHub，都附上简短、具体的中文提交说明，说明改了什么；不能只写“update”“修复”或“同步代码”。一次包含不同阶段的改动时，在提交正文补充范围和验证结果。

示例：

```text
完善多租户沙箱准入与申请界面，补齐回归文档

增加审核式企业身份初始化、额度与撤权复验。
更新操作指南和测试报告；生产开通仍保留门禁。
```

推送前完成相关测试、构建、文档链接与源码敏感信息检查，核对远程仓库和提交差异。不得提交密钥、私有配置、用户数据库、模型文件、临时浏览器状态或本地测试输出。已有用户改动不能重置；远程分支发生变化时先检查，不强制覆盖。

交付说明给出提交号、中文摘要和剩余边界。已推送不等于已部署；未经明确安排，不重启在用服务、迁移真实数据或开放公网。
