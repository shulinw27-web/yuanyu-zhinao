# 开发路线

更新：2026-09-07。已有能力见 [当前状态](../overview/PROJECT_STATUS.md)，历史验收见 [归档](../archive/README.md)。本页只安排后续工作，不重复维护完成清单。

| 阶段 | 工作重点 | 进入条件 | 可验收的输出 |
| --- | --- | --- | --- |
| 1. 建立真实数据通道 | 选一套系统和只读业务场景，核对认证、分页、增量、异常与脱敏 | 沙箱、只读账号、API、字典和样例齐全 | 连接器契约测试、字段映射、来源记录、对账结果 |
| 2. 建立可用语义模型 | 通过语义运营 Agent 提取候选，人工校对对象、关系、主键和分级 | 有可追溯的数据结构和业务口径 | 草稿 Diff、校验报告、发布版本、语义查询结果 |
| 3. 智脑读取与回答验收 | 对真实授权数据做检索、分析、多轮追问与记忆撤销测试 | 身份映射、数据域和模型部署明确 | 正确/拒绝/澄清样例集、证据与源数据核对 |
| 4. 受控业务写入 | 从草稿或审批开始，处理幂等、重试、补偿和回执 | 写入契约、沙箱审批流程和最小授权到位 | 正向流程、重复请求、越权、超时及人工恢复测试 |
| 5. 生产基础设施与多端联调 | 对已实现的 PostgreSQL/消息/密钥/端侧适配接入真实环境 | 独立测试环境与凭据托管可用 | 迁移/回滚、撤权、任务恢复、签名与监控证据 |
| 6. 上线验收 | 安全、稳定性、容量、灾备及业务 UAT | 前述环节闭环 | [生产 Checklist](../operations/PRODUCTION_TODO_CHECKLIST.md) 中对应证据和上线结论 |

准备材料按 [开发准备事项](DEVELOPMENT_READINESS.md) 收集。未取得外部环境时，可以继续维护契约、Mock 样例和失败分支测试，但不能把这些工作勾选为真实接入完成。

## 每次迭代的验证

2026-09-07 在事件日期/来源版本查询、Demo 报警绑定草稿和结构化记忆基础上，新增来源完整性声明约束下的历史时点查询与受控样本映射后端入口。全量回归 298 项通过；真实模型、浏览器及企业联调仍未验收，其他业务的指定对象写入未开放。具体改动和边界见 [Agent 改进记录第四批](AGENT_RUNTIME_IMPROVEMENT_2026-09-06.md)，连接协议见 [接入指南](SEMANTIC_DATA_CONTRACT_GUIDE.md)。

```powershell
npm run docs:check
npm run quality
npm run build
npm run build:desktop
npm run build:mobile
```

涉及 Python 语义服务时还需运行其专项测试；涉及发布时还需迁移校验和目标环境验收，见 [开发指南](GETTING_STARTED.md) 与 [部署回滚手册](../operations/DEPLOYMENT_ROLLBACK_RUNBOOK.md)。测试数量以该次命令输出为准，不把旧基线数量写成当前值。
