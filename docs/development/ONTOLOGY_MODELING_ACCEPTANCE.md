# 本体建模改进与验收记录

日期：2026-09-09。结论：本轮开发增量通过本地回归，不是完整本体平台或企业生产验收。

## 实现范围

- 分离通用场景与 OA 审批模板校验，取消通用对象和关系数量下限；保留治理、权限和发布边界。
- 增加目标、验收问题、粒度、关系证据/时间元数据、判断和动作声明绑定。
- 增加内置质量处置判断及九个合成回放案例，接入智脑现有非定向质量分析。
- 保存已发布定义，记录精确判断版本；模型指纹纳入场景、状态机和事件，保存修改后清除旧构建结果。
- 模型内的判断、动作依赖影响可追踪，但不声称覆盖外部消费者。
- 采购演示结果标注 Mock、无外部回执、业务未完成；生产/禁用 Mock 时拒绝这条演示写路径。
- Semantica 服务允许独立对象类型并保留新增模型元数据，拒绝空模型和部分畸形资产，避免静默丢弃。
- 两处建模 UI 区分本地演练与独立服务验证，未保存修改阻止校验、模拟和登记。
- 质量判断增加三项直接字段映射、等级/新鲜度受限参数及版本指纹；运营与管理 Web 共用配置和样本回放组件。
- 1–100 条授权样本可按指定时刻对比草稿与发布定义；只保存结果与版本引用，支持发布主体/当前指纹的回放门禁。
- 人工与 Agent 共用固定版本发布协调器，检查回执版本/指纹、并发互斥及草稿漂移；不确定结果只读对账，不自动重发或补偿。
- 追加有界实例关系双时间查询：补录、完整修订快照、撤回、有效期、基数与竞争修订冲突；接入原案例回放、版本比较及报告隔离。
- 页面支持 JSON 文件导入（不自动执行），中文结果和有效/已知时刻展示；编辑输入使旧报告失效。
- 跨系统身份追加：显式来源→统一编号核验、系统命名空间、类型/粒度、范围与双时间修订校验；同名同号无映射时保持未解析，多重映射报告冲突，不做写回迁移。

测试过程没有向方舟发送本轮真实多轮请求，没有访问企业 ERP/WMS，也没有执行电脑上的业务操作。模型对话智能、端到端业务效果和真实 Semantica 部署不能用这些结果代替。

## 回归中发现并修复的问题

1. 空的人工确认依据被默认“建模草稿”覆盖，误通过证据校验。改为保留显式空值并阻断。
2. 质量/市场分析将身份对象传入只接受 subjectId 的权限接口，导致应可见风险被过滤。改为显式传递用户编号，新增未知身份仍拒绝的反例。
3. 独立语义服务只允许五类核心锚点，与平台支持独立类型不一致。对齐校验，独立类型不产生任何权限。
4. 运营页面固定显示 Semantica 构建成功，即使独立服务未连接。改为依据结果分支显示，并与管理 Web 复用提示函数。
5. 编辑后仍可沿用旧校验按钮。增加未保存状态拦截；服务器保存后也清除旧模拟结果。
6. 模型指纹未包含场景、状态机和事件。纳入指纹，防止相关修改漏过并发/回滚检查。旧快照如无法匹配新指纹会保守拒绝，不自动覆盖。
7. 重复点击发布仍可能请求独立服务。新增已发布状态前置拦截；测试要求外部调用次数保持为一次。
8. 保存/校验响应未回传草稿指纹。补齐返回值，使保存后的页面可直接执行精确版本回放。
9. 记录准入把身份缩为字符串，丢失服务端验证过的 Demo 来源，导致合法组织样本误拒绝。保留完整认证上下文，并增加无来源的伪 Demo 账号仍拒绝的测试。
10. 独立服务响应超时、错版本或草稿中途改变时可能产生两端状态偏差。增加固定操作版本、只读对账及比较后提交；单测覆盖丢失响应、错误版本/状态/指纹、并发和草稿漂移。
11. 窄屏同时固定导航和标题栏会互相遮挡。小屏只固定导航，标题栏恢复正常文档流并允许操作区换行；同时修复未配置回放门禁时下拉框空白。

浏览器截图位于 `output/playwright/ontology-case-replay-desktop.png` 和 `output/playwright/ontology-case-replay-mobile.png`，属可再生测试产物。最后 UI 调整后重跑 Lint、类型检查、运营端构建与 6 项布局回归。

历史关系追加回归覆盖：晚到修订、区间边界、撤回、同时间冲突、基数冲突、推断/声明需复核、未来修订越权、悬空端点、错误来源、重复版本、变更身份、时刻与数量限制、端点尚不可知、模型有效期、跨版本比较及不保存原始 payload。浏览器使用独立内存 API，验证 JSON 导入和中文结果；截图为 `output/playwright/ontology-history-desktop.png` / `ontology-history-mobile.png`。无真实企业数据、模型调用或业务写入。

## 下一步边界

本轮没有完成通用规则编译器、任意模型到工具自动适配、数据库级全量时态索引及多跳查询、跨系统历史身份迁移、真实 ERP 回执与补偿。有界实例样本时态计算已实现，但未取得企业历史样本或真实多轮对话验收，也未自动接入智脑自然语言查询。独立服务发布对账采用注入适配器与 HTTP 模拟服务测试，不代替线上演练。后续按 [生产 Checklist](../operations/PRODUCTION_TODO_CHECKLIST.md) 继续，使用步骤见 [场景建模指南](../guides/ONTOLOGY_SCENARIO_MODELING.md)。

身份样本核验已完成开发基线，不等于完成企业实体解析或持久化编号注册；报告只保存解析状态、时刻与数量，不保存来源编号、统一编号或 payload。新增专项覆盖确认/未确认、缺失、多重映射、同系统重复版本、跨系统同 ID、类型/粒度不符、晚到撤回、修订重分配、越权、非法来源、边界输入和版本比较。两边查询同一来源时有效映射计数去重，避免重复统计。

编号核验浏览器截图为 `output/playwright/ontology-identity-desktop.png` 与 `ontology-identity-mobile.png`；独立内存测试服务，不修改用户运行草稿。文档同步范围为操作指南、API/OpenAPI、架构说明、两端能力范围、项目状态和生产清单。
