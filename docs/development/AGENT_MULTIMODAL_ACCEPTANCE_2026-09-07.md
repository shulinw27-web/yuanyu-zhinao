# 双端多模态验证与修复报告

日期：2026-09-07。对象：业务智脑、语义运营 Agent。模型：火山方舟 `doubao-seed-2-1-pro-260628`。

## 验收结论

本轮完成支持格式的内容解析、跨轮追问、跨文件核对，以及语义候选生成的开发修复。真实模型的文件理解与追问 40/40、边界场景 8/8、候选模型 2/2 通过；浏览器中另核对了两端各两轮，共 4 次回复。测试均使用合成材料，没有接入或读取真实 ERP 等企业数据。

这不是“任意多模态文件都能准确理解”的承诺。正式运行实例仍保留默认图片出网限制。测试中的图片视觉调用使用独立内存进程和仅认可合成文件精确哈希的扫描替身，不能作为企业病毒扫描、DLP 或生产出网审批已经完成的证明。

## 发现的问题与修复

| 编号 | 问题及影响 | 修复与验收结果 |
| --- | --- | --- |
| MM-01 | XLSX 把共享字符串与单元格索引摊平，数值可能关联错记录 | 按工作表、行号、单元格坐标解析共享字符串、富文本与内联字符串；两端准确读取 RT-101 的 137.50 CNY |
| MM-02 | Word 格式片段之间被插入空格，字段名被拆开；表格失去列关系 | 连续文本片段正确拼接，段落与表格行列分别标记；`asset_` 与 `code` 恢复为 `asset_code` |
| MM-03 | 长文件在附件预检阶段因抽样文本过长被误拒绝；后续又静默截断 | 限定预检抽样，解析文本分段检查；显式记录摘录字数、缺失页及截断状态 |
| MM-04 | 多文件共用一个截断窗口，前面的文件可能挤掉后面的文件 | 按附件分配摘录预算，保留文件名与内容哈希；两个附件可通过 `asset_code` 关联，也能指出金额冲突 |
| MM-05 | 图片只有 OCR 接口占位，没有完整视觉理解链 | 增加受控视觉观察，再对观察结果执行脱敏与内容检查；PNG/JPEG/WEBP 的文字、箭头、基数和示例金额通过真实模型测试 |
| MM-06 | 扫描 PDF 无文字；有标题的扫描页容易被当作已完整读取 | 识别空文本和含图页面，受控渲染后走 OCR 或视觉模型；保留页码及未识别页面，混合 PDF 通过 |
| MM-07 | 本机两个 Canvas 版本混用，PDF 渲染测试进程异常退出 | 统一为已验证的 `@napi-rs/canvas 0.1.100`；增加图片像素及页面渲染范围约束，释放 PDF 资源后回归通过 |
| MM-08 | OCR 文本可引用被误当作原图可出网 | 独立校验 `rawImageEligible`；原图要求企业扫描明确允许和出网审批。DLP 的 redact 结果、仅文字通过或未明确允许都不放行原图 |
| MM-09 | 附件摘要过长会在记忆链静默丢失，用户不知缺了什么 | 保留有限的受控摘录，并携带“未完整保留”的提示；未读到的尾部金额不能猜测 |
| MM-10 | 图片中的 PK/FK 可以解释，但外键候选校验不接受 FK 或跨行证据 | 允许从已逐字核对的字段证据识别 PK/FK；图片生成 Asset、RepairTicket 两个对象和一条外键关系，仍等待校对 |
| MM-11 | 未读全或被隔离的附件仍可能落入通用建模路径 | 当轮及后续追问均拒绝从不完整附件或截断记忆生成完整候选；要求重新上传或缩小范围，不用模板代替理解结果 |
| MM-12 | 真实回复把币种 CNY 写成 CY，宽松断言未发现 | 增加币种字面值核对、一次限时修复和严格断言；不能核对则明确失败，不自动改写成猜测值 |
| MM-13 | 用户看不到附件到底读了多少 | 两端增加“附件读取范围”，区分摘录可引用、部分读取、未读取/已隔离，展示缺失页和格式限制 |

以上可开发修复项已完成。企业内容安全服务、生产原图出网审批、真实复杂材料验收属于外部前置条件，仍保留待办。

## 使用与验收限制

单次最多 5 文件、单文件不超过 4 MiB、合计不超过 12 MiB。PDF 最多处理前 20 页，其中最多渲染 3 个需要视觉识别的页面；超出的页面会标记未完整读取。Office 最多 200 个压缩包条目、声明展开总量 20 MiB；XLSX 最多 20 张表、每表 2,000 行、每行 200 格。对加密、损坏、包含嵌入对象等不支持材料应拒绝，不能当作已理解。

本轮只覆盖清晰合成关系图和小型字典/表格，不覆盖手写、严重倾斜/模糊、多栏复杂文档、密集大图、音频或视频文件。Word 的正文以外对象，Excel 图形/透视表及公式重新计算，不能视为已支持。模型生成的视觉观察仍须人工核对，不是确定性的 OCR 正确率保证。

素材制作使用文档、PDF、表格技能：Word 以段落和表格组成，Excel 保留数值类型，图片/表格预览已检查；PDF 实际通过页面渲染和视觉调用验证。Word 的独立页面预览未完成：文档技能的渲染步骤因本机未配置 LibreOffice 而失败。因此 Word 结论限于内容解析和问答，不包含版式验收。
