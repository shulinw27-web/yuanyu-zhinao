## 复测与操作入口

- `npm run test:all`：常规全仓回归。
- `npm run test:semantic-review`：审核分派、权限及并发修订。
- `npm run test:knowledge`：资料、笔记、问答、关联与权限。
- `npm run test:material-review`：企业资料协作核对、独立来源授权、职责分离与HTTP权限。
- `npm run test:packaged-electron` / `npm run test:packaged-electron -- --portable`：已构建Windows包的隔离启动。
- `npm run security:licenses -- --registry --require-known`：显式查询官方精确版本声明，不发送文件或凭据。
- `npm run test:weknora-stability`：默认12轮、隔离并发2；最长30轮、并发4，失败保留脱敏诊断。
- `npm run test:semantic-instances`：真实Semantica临时进程，不静默跳过缺失依赖。
- `npm run evaluate:weknora -- --live-synthetic`：仅既有授权合成知识库只读，不加`--answer`或`--hybrid`。
- `npm run check:ark`：模型连接和输出契约检查，不代表完整智能质量评测。
