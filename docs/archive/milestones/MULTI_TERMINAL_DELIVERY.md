# 多端私有 Agent 交付说明

> 历史阶段记录：保留验收与演进依据，不作为当前完成度或操作入口。当前状态见 [项目状态](../../overview/PROJECT_STATUS.md)。

## 多端职责

| 终端 | 核心用户 | 主要职责 | 不承担的职责 |
| --- | --- | --- | --- |
| 移动端 | 业务人员、值班人员、管理层 | 智脑对话、语音指令、主动告警、任务确认、审批和回执 | 系统连接、密钥管理、世界模型建模 |
| PC Web/桌面端 | 运营、IT、数据治理、管理员 | 监控大屏、风险态势、Agent 运营、世界模型与连接配置、权限和通知治理 | 员工的日常业务入口 |
| 服务端智脑运行时 | 平台 | 联合权限判定、任务规划、工作流、工具调用、审批、审计 | 将任何长期密钥下发至客户端 |

## 移动端工作流

```text
告警推送 / 用户指令
       ↓
移动端智脑会话
       ↓
身份、角色、设备与策略检查
       ↓
世界模型受控查询 + 专业技能编排
       ↓
建议卡 / 确认卡 / 审批工作项
       ↓
受控系统操作 + 审计回执
       ↓
移动端状态更新
```

## 已交付工程

- `apps/mobile`：主入口应用。提供智脑对话、语音入口、7×24 监控状态、优先告警、任务待办、通知列表和确认卡。
- `apps/desktop`：PC 运营控制台。提供监控指标、风险态势、系统状态、Agent 运行指标和治理说明，不提供日常业务对话输入。
- `frontend`：PC Web 管理端。提供大屏、风险、世界模型、Agent 运营、通知渠道和配置中心。
- `packages/agent-sdk`：多端共用的会话注册、设备标识、通知订阅和 Agent API 客户端。
- `backend`：智脑运行时、联合权限控制、确认式工作流、审计模拟及世界模型连接模板服务。

## 移动端安全要求

1. 移动端只持有用户登录会话和受控设备标识，不持有模型、KMS、系统连接器或通知渠道密钥。
2. 每次请求均由服务端核验用户、智脑服务主体、设备、租户、角色、数据范围和动作风险；有效权限取其交集。
3. 移动端通知内容按数据分级脱敏；点击通知后再次鉴权才展示详情与处置能力。
4. 语音原文仅可进入企业私有 ASR 服务，并按数据保留策略删除；Demo 的浏览器语音能力仅用于演示。
5. 写操作始终先产生可审计的工作项；质量、资金、外发和系统写入必须经过确认与审批。

## 生产化替换项

| Demo | 生产实现 |
| --- | --- |
| `x-demo-role` | OIDC/OAuth 2.1 + PKCE，服务端验证用户、租户、设备和 scope |
| 内存会话和工作项 | PostgreSQL、Redis、事件总线和可回放审计仓 |
| 浏览器语音识别 | 企业私有 ASR 或经批准的原生语音插件，音频加密传输 |
| `in_app` / 模拟 push | APNs、FCM、短信、邮件、企业微信、钉钉和签名 Webhook 适配器 |
| `localhost:3001` | 内网 API 域名、API Gateway、mTLS、证书固定策略 |
| Mock 模型 | 内网 vLLM/Ollama/OpenAI-compatible 网关及 KMS 动态凭据 |

## 构建

```powershell
npm.cmd run build
npm.cmd run build:desktop
npm.cmd run build:mobile
```

生成原生安装包需安装 Rust/Cargo；Android 还需 Android Studio/SDK，iOS 需 macOS/Xcode。原生构建时应按最小权限原则分别启用麦克风、通知、相机或文件能力，禁止为开发便利开放全量本地文件权限。
