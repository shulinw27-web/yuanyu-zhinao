# 私有 Agent 平台验收与生产化清单

> 历史阶段记录：保留验收与演进依据，不作为当前完成度或操作入口。当前状态见 [项目状态](../../overview/PROJECT_STATUS.md)。

## 产品原则

智脑是唯一的业务智能入口，移动端是该入口的主要载体。世界模型、专业能力、系统连接器、监控、权限与密钥中心都是智脑的受控能力层；PC 端用于观察和治理这些能力。

智脑是权限管理系统中的独立服务主体，默认不具备业务数据和工作流权限。有效权限必须同时满足：用户角色权限、智脑主体权限、可信设备会话、数据分级策略及工作流策略；策略中心仅为本次调用签发短时凭据。

## 验收步骤

1. 在移动端确认首页展示“7×24 监控已开启”、运行状态、优先告警、待办数量和最近处置闭环。
2. 点击优先告警并要求智脑提供处置建议，确认返回的证据与计划只覆盖当前角色与智脑共同允许看到的数据。
3. 输入生产、市场或内务相关指令，确认智脑路由至对应专业能力；无智脑领域授权时应明确拒绝，而不直接获得跨域数据。
4. 发起采购等高风险任务，确认先出现确认卡与审批工作项，且只创建受控 ERP 草稿。
5. 在 PC 控制台确认可查看风险、系统状态、队列、审计覆盖率和 Agent 运行健康度，但没有面向员工的日常对话输入。
6. 在 Web 管理端确认可以配置世界模型模板、连接器、模型、通知渠道、权限与密钥引用；浏览器中不显示密钥明文。

## 生产化替换项

- 将内存任务、通知和版本数据替换为数据库、事件流与可回放审计仓。
- 接入企业 IAM、KMS/HSM、设备信任、审批系统及 ERP/MES/LIMS/QMS/OMS 等受控连接器。
- 将 Agent 指标接入 OpenTelemetry/Prometheus；以 APNs/FCM、短信、邮件和签名 Webhook 实现真实通知。
- 为技能包建立签名、版本、灰度、回滚、离线评估和生产变更审批流程。
- 在内网模型网关执行模型调用；模型密钥只由部署环境或 KMS 注入。

## 告警策略基线

| 等级 | 移动端行为 | Agent 行为 | 人工要求 |
| --- | --- | --- | --- |
| P0 | 即时推送、持续提醒、升级值班人 | 汇总影响范围，生成冻结/通知建议 | 必须确认并进入审批 |
| P1 | 推送至责任人 | 生成调查或处置草稿 | 责任人确认 |
| P2 | 汇总推送或订阅推送 | 趋势分析和建议 | 可延后处理 |

## 采购条线权限基线

| 角色 | 可由智脑发起的动作 | 明确禁止 |
| --- | --- | --- |
| 生产负责人 | 提交采购需求草稿 | 创建 ERP 采购申请、批准采购 |
| 采购负责人 | 提交采购需求、发起采购流程 | 批准采购 |
| 质量经理 | 创建质量调查草稿 | 发起或批准采购 |
| 管理层 | 发起采购流程、批准采购 | 绕过确认、审批与审计 |

## 非功能要求

- 每次请求均需服务端验证用户、智脑服务主体、设备、数据域及工作流权限并审计，不能相信客户端传入的角色或动作风险。
- 告警推送只发送最低必要信息；详情展示和动作执行均需重新鉴权。
- 高风险操作遵循“计划 → 用户确认 → 审批 → 执行 → 回执”闭环。
- 移动端与桌面端均不得直连业务系统或保存任何高权限凭据。
- 图片、PDF 与语音材料必须先经过多模态接入策略、数据分级与审计；外部视觉模型上传需单独审批，默认禁止附件原文出域。
