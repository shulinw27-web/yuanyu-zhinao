## 1. 产品定位

身份与权限补充（2026-09-08）：已支持钉钉及多 OIDC 身份源适配，明确绑定到平台账号；切换来源不自动扩大权限。其他平台专用免登和组织角色同步尚未实现，见 [适配范围](../guides/IDENTITY_PROVIDER_ADAPTERS.md)。

智脑是面向业务人员的对话式工作台：理解用户诉求，在当前权限内查找证据、分析业务问题、整理日常工作，并在明确确认后调用已开放的业务或桌面工具。

它不是语义模型管理端，也不是拥有整台电脑控制权的通用自动化助手。语义对象、来源映射、模型校验和版本发布由独立的元域智语端负责。

当前业务查询主要基于 OA、ERP、WMS、MES、LIMS、QMS、OMS 等系统的受控模拟数据。系统名称出现在页面上，不代表已经连接对应企业系统。

## 3. 对话、记忆和任务的具体范围

### 同一任务内

用户可以连续说“列三个问题”“解释第二个”“截止时间改成周五，其他不变”。模型会接收经权限过滤的历史、摘要、结构化索引和有限材料摘录，优先采用最新更正。

当前理解入口的历史上限为 28,000 字符；材料与当前输入另有限额。页面上的会话存储预算不等于每次实际发给模型的上下文。内容过长时会选择、截取或压缩，重要约束仍应明确表达和核对。

### 跨任务及长期记忆

新任务不会默认继承其他任务的完整消息。用户主动“固定为长期记忆”的目标才进入长期目标机制；当前默认保留 90 天，可撤销。权限变化后，旧受限内容不能继续作为可访问上下文。

任务持久化、长期目标和学习信号是三件不同的事情：保存聊天用于继续任务，不代表获得训练授权；记住目标也不代表用户批准执行该目标涉及的动作。

### 任务编排

系统可以选择已登记的只读工具、组织查询与证据分析；涉及业务写入或电脑操作，必须进入独立的受控执行流程。当前不是让模型任意编写代码、创建工具或无限循环自主执行。

桌面长任务支持排队、派发前暂停/恢复/取消和超时处理。任务已派发或运行后不能保证取消，也不会为消除超时提示而盲目重复执行。持续执行依赖相应 Worker 和可信设备在线。

## 4. 业务处理范围

### 查询与分析

可以基于授权可见记录汇总异常、解释报警、提出排查顺序，并查看对应证据。当前覆盖库存、采购、生产质量等演练链路，以及组织、审批和待办等相关对象。

必须区分三类内容：已经读取到的事实、尚未证实的可能性、建议采取的措施。有限样本不能推导全公司结论；不同系统记录缺少关联键时，不能断言属于同一批次或存在因果关系。

### 写入与审批

现有流程包含采购需求、质量异常调查、市场投诉处置、预算与供应商核验等受控草稿，以及采购协同演练。具体能调用哪项由当前角色、数据范围、目标绑定和工具状态共同决定，不是所有用户都可以发起所有流程。

“帮我分析报警”仅表示分析需求，不表示同意创建申请、冻结库存或完成审批。即使已创建草稿，也不表示业务审批通过，更不表示正式订单已发送到真实 ERP。

对于指定编号的业务写入，当前对象绑定能力是按工具实现的；已具备受控质量调查草稿的相应路径，不能据此宣称任何流程都支持任意编号。

## 5. 桌面与文件能力

| 开放工具 | 实际范围 |
| --- | --- |
| 新建文本 | Markdown、TXT、CSV |
| 新建 Word | DOCX 草稿，不等于完整 Word 应用控制 |
| 新建 Excel | XLSX 工作簿，不等于任意公式建模或编辑已有工作簿 |
| 打开网页 | 在系统浏览器打开受允许的 HTTPS 地址，不自动操作页面 |
| 读取本机文本 | 专属工作区中的 Markdown、TXT、CSV，单次不超过 512 KiB |
| 写剪贴板 | 把生成的纯文本写入系统剪贴板，不读取原有内容 |

文件目标可以识别桌面、文档、下载目录，实际写入所选目录下的“元域智脑工作区”；未指定位置时默认桌面。任意绝对路径、目录穿越、链接文件、覆盖和删除不在允许范围内。

网页端能够交流和形成计划，但不能冒充 Electron 在电脑上完成写入。只有端侧回执核验完成，才能报告文件已生成。上述文件类型也不意味着支持生成 PDF、PPT 或任意办公格式。

## 6. 材料、多模态与数据使用

当前附件准入包含 JPEG、PNG、WEBP、PDF、DOCX、XLSX、JSON、YAML 和 CSV；实际提取能力取决于内容、安全扫描及适配器。文本型 PDF 与扫描版 PDF、结构化表格与复杂排版文档不能视为同一能力。

2026-09-07 已使用真实方舟验证 JSON/YAML、Word、Excel/CSV、PNG/JPEG/WEBP、扫描与混合 PDF 的合成材料，以及不重复上传的后续追问。Excel 保留行列与单元格对应关系，Word 保留正文段落与表格；两端提供“附件读取范围”，截断及未识别页面不当作已读全文。图片测试在获准的合成测试进程进行，实际 API 原图出网仍默认关闭，需企业扫描与审批后启用。音频/视频和任意复杂扫描件不在通过范围，详见 [多模态指南](../guides/AGENT_MULTIMODAL_GUIDE.md)。

当前配置使用火山方舟云端推理。发给模型的上下文受脱敏、准入和出网策略约束，因此不能将本次运行描述为完全离线或数据永不出本机。公司原始数据不会被项目自动拿去微调模型；供应商侧的数据处理条款仍需企业单独核定。

工作流学习默认关闭。开启后只采集允许工具经本人确认且成功执行的最小化信号，不采集原始提问、文件正文或企业载荷作为学习信号；关闭授权会清理相关信号。它不赋予跳过确认、审批或数据权限的能力。

## 7. 权限边界与不支持事项

身份、角色、组织数据域、会话和设备共同约束访问。模型只能提出建议或动作意图，不能自行授权。用户输入、上传材料、历史聊天中的“管理员指令”也不能改变权限。

当前不应承诺：

- 自主操作任意桌面软件、浏览网页并点击表单、执行任意终端命令。
- 自动发送邮件、对外上传、支付、签署、删除文件或覆盖原文件。
- 未接入系统的实时数据查询，或仅凭 Mock 数据输出正式企业报告。
- 无限记忆、跨用户共享记忆、未经同意学习个人信息或训练公司数据。
- 由业务智脑直接编辑和发布语义模型，或绕过质量、财务和采购审批。
- 一次测试通过即可保证任何问题、任意文档或所有生产场景都能可靠处理。

## 9. 可直接试用的场景

1. “用当前可访问的库存模拟记录分析三个关注点，不要生成文件或发起业务流程。”随后问“第二点具体是什么意思？”——应先读取证据，再承接解释，不出现文件确认卡。
2. “明天 9 点开会、11 点前交周报、下午核对合同。”随后说“周报改成 10 点半，其他不变。”——应保留未更改事项，不触发企业系统查询。
3. 在可信桌面端提出“将这份工作清单生成 Word，保存到文档目录。”——应先展示目标目录和待确认动作；确认及执行成功后才出现产物回执。
