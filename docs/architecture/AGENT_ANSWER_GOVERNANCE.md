# 智脑回答治理规范

> 版本：answer-governance.v1　更新日期：2026-09-01

## 1. 适用原则

智脑不采用模型自报的概率作为业务置信度。置信等级只根据服务端可验证证据计算：两条及以上受控证据为 `high`，一条为 `medium`，业务回答无证据为 `low`；自然语言闲聊和策略拒答为 `not_applicable`。

每次回复返回 `answerGovernance`，包括引用状态、证据数量、置信等级、不确定性、拒答状态、是否需要人工复核和纠错策略。原始回复、证据和审计记录不可被后续纠错覆盖。

## 2. 输出规则

- 业务结论必须显示可核验来源；无证据时明确提示不确定，并禁止据此执行写操作。
- 安全或权限拒绝必须标记为拒答，说明策略原因，但不得泄露内部 Prompt、规则细节或敏感上下文。
- 所有待确认命令、审批草稿、记忆选择和缺参状态均要求人工复核。
- “计划完成”“数据读取完成”不得表述为“申请已完成”或“业务已执行”；完成状态只来自受信工具的外部回执。
- 用户纠错保留为同一任务的新版本反馈，不改写原回答、原证据或 Evidence Trace。

## 3. 质量评测

离线控制评测覆盖证据引用、数据域边界、采购确认门禁、直接/混淆/编码提示词攻击，并直接断言回答治理字段。生产评测还需使用经批准的脱敏业务集，统计正确率、引用完整率、拒答准确率、人工接管率和工具成功率。
