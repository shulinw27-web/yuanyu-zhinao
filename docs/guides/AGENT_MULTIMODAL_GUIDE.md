# 两端多模态使用及接入指南

更新：2026-09-07。智脑负责业务资料分析，语义运营负责字典解释与候选建模；上传附件不会自动授权查询企业系统、保存草稿或发布模型。

## 怎么测试

在智脑中新建任务，点击“上传图片或文档”，选择合成 `tickets.xlsx`，提问：

> 只分析附件，不读取系统、不生成文件。RT-101 的资产编号、维修金额和单位是什么？

预期为 AS-01、137.50、CNY。下一轮不重复上传，问“另一笔 RT-102 是多少，两笔合计多少”，预期为 22.50 和 160.00 CNY。

在语义运营中新建任务，点击“添加材料”，选择合成 `dictionary.docx`：

> 只解释字典，不建模、不保存、不发布。RepairTicket 的主键、外键和金额字段分别是什么？

预期为 ticket_code、asset_code、repair_cost。随后可以追问关联到哪张表、关系基数是什么；只有明确要求形成候选提案，才进入建模流程。不要将“已生成候选”理解为模型已发布。

合成文件位于 `output/multimodal-fixtures/`；如需重新生成，使用 `scripts/fixtures/build-multimodal.py` 和 `scripts/fixtures/build-multimodal-sheet.mjs`，后者需要以 `ARTIFACT_TOOL_ENTRY` 指向已配置的文档运行时。标准答案在该目录的 `ground-truth.json`。

## 读到了什么

两端回复中都提供“附件读取范围”。先看具体文件是否为摘录可引用、部分读取、未读取/已隔离，再判断回答。

- Excel 保留工作表名、行号、单元格坐标和数值对应关系。公式只引用缓存，未重新计算；没有缓存时不能当作 0。
- Word 解析正文段落和表格，连续格式片段不会拆开字段名。图片、文本框、页眉页脚、批注与修订记录不作为完整正文理解。
- PDF 保留页码。扫描页或图文混合页需要视觉能力；“读到了标题”不代表读懂了页面里的图。
- 图像识别区分可见事实与解释。不清楚的文字、数值和箭头需要用户复核，不能把模型观察当作权威数据。
- 多文件按文件名与内容标识分别引用；同一编号的数值冲突应列出不同来源，不能自动选一个覆盖另一个。

单轮附件摘录总预算不超过约 24,000 字符，并按文件分配；会话理解另有 28,000 字符历史预算，组合提示安全上限 64,000 字符。智脑附件记忆最多保存约 8,000 字符、回带约 6,000；语义端最多保留约 12,000。达到预算时保留缺失提示，不代表系统保存了全文。大字典应拆分，重要资料需要再次上传或缩小范围。

## 图片与扫描 PDF 的启用条件

当前实际 API 默认不允许原图云端传输。文本解析可直接走现有受控通道；图片有两种配置路径。

第一种是企业 OCR：配置 `MULTIMODAL_OCR_ENDPOINT`，由批准的内网服务返回文本。OCR 文字进入内容检查与脱敏流程，原图不会因为文字已通过而自动进入方舟。普通 OCR 不保证理解箭头、图例或布局。

第二种是视觉模型：需要同时满足以下条件，而不是只改一个开关。

| 配置/条件 | 要求 |
| --- | --- |
| `MULTIMODAL_VISUAL_PROVIDER` | `model`，默认 disabled |
| 模型提供方 | 已配置、允许使用且实际支持图像的 Ark 或 OpenAI；本轮验证 Ark |
| `AGENT_EXTERNAL_MULTIMODAL_MODE` | 经企业批准后设为 approved，默认 metadata_only |
| `MULTIMODAL_SECURITY_SCAN_ENDPOINT` | 批准的企业扫描服务，明确返回 clean=true 且 dlpAction=allow |
| DLP 要求脱敏 | 当前不接受“文字脱敏成功”替代原图脱敏；redact 不放行原图 |
| 安全失败/模型失败 | 不猜内容，显示不可用、未读取或已隔离；不生成完整模型 |

扫描服务请求包含原文件，自己也需要纳入企业网络与数据处理审批。OCR/扫描默认限制为私网地址并拒绝重定向；不要通过外网放行开关绕过审批。

本次自动测试仅在隔离进程中为合成文件启用视觉，未更改正式运行实例的出网权限。接入生产前仍需真实 AV/DLP 服务、凭据、可用性及业务样本验收；测试脚本里的精确哈希扫描替身不可用于生产。

## 当前不支持

音频和视频文件没有此次端到端验收链。界面的语音输入按钮不等于支持录音文件分析。没有实现任意长文档全文记忆、Excel 任意公式重算、自动理解全部 Office 图形、无审核发布语义模型，也不能保证模型零误差。

具体限制、发现的问题和证据见 [双端多模态验证报告](../development/AGENT_MULTIMODAL_ACCEPTANCE_2026-09-07.md)。
