## 入口与定位

首批改版入口（2026-09-14）：

- `#/product`：智脑工作台详情；`#/semantic`：元域智语详情，两者不再重复首页。
- `#/demo`：六步固定合成案例，支持步骤切换、重置、Agent切换和对象来源查看。不发起模型或企业业务请求。
- `#/architecture`：点击四个概念层查看职责、组件与权限边界，不等同部署拓扑。
- `#/pricing`：方案与交付路径；不展示正式价格。测试金额仍在客户中心账单内。
- `#/docs/walkthrough`：双Agent逐步教程。文章章节可分享，例如`#/docs/walkthrough?section=section-3`；刷新和返回恢复当前章节。文章复制链接不带章节参数，章节标题和右侧目录可取得章节地址。

文档提供分组搜索、命中片段、无结果提示、代码复制、前后篇导航；移动端通过“展开文档目录”选择文章。产品详情里的截图是项目既有演示环境验证截图，图中连接与模型状态为当时状态，不代表当前租户已接通。

- 官网：http://127.0.0.1:15195/ 。介绍元域、双Agent产品体系、语义层架构、业务场景与能力边界。
- 文档中心：http://127.0.0.1:15195/#/docs 。公开文档包含快速开始、架构、语义建模、计费、权限和门户API。
- 客户中心：http://127.0.0.1:15195/#/console 。注册、登录、组织、成员、测试订单与会员管理。
- 平台运营：http://127.0.0.1:15195/#/admin 。仅向经服务器本地授权的管理员开放。

这不是替换智脑或元域智语端，而是在其前面增加产品获客与客户管理入口。当前商业控制面和企业执行面尚未建立生产开通桥接，不能用门户账号直接读取企业业务数据。

## 本地启动

在项目根目录分别运行：

```powershell
npm run start:portal-api
npm run dev:portal
```

前端15195，API15196，均绑定127.0.0.1。API使用独立文件`backend/.data/product-portal.db`，默认启用明确标记的本地测试支付。不开放真实微信、支付宝、银行卡或外部Webhook。

只启动账号与订单管理、不允许模拟到账时：

```powershell
node scripts/product-portal-runtime.mjs
```

可通过PORTAL_SQLITE_PATH选择独立测试数据库。PORTAL_API_PORT仅改变API监听端口；同步调整Vite代理与受信Origin才能更换前端地址。不要把本机绑定改成公网地址来绕过上线门禁。NODE_ENV=production会拒绝启动当前门户。

## 账号与管理员

1. 打开注册页，使用测试邮箱、姓名和12至128位测试密码。
2. 阅读测试服务和数据说明后注册，再登录。
3. 如需验证平台后台，先注册你自己控制的账号，再从项目根目录执行：

```powershell
npm run portal:admin -- your-account@example.com
```

该命令只提升已存在的正常账号，记录审计并撤销其旧会话；重新登录后出现“平台运营”。没有首个注册用户自动管理员、默认管理员密码或公开提权接口。

邮箱目前只是账号标识，未验证邮箱所有权。真实邮箱/短信验证、密码找回、MFA与企业SSO尚未接入；当前账号不可当作真实企业员工身份凭证。

## 租户与团队

所有者创建企业名称和唯一空间标识后，得到`provisioning_pending`开通记录。平台管理员可以设为`sandbox_ready`或暂停，但`runtimeConnected`始终为false：只开通了门户管理空间，没有创建生产智脑实例、数据库命名空间或业务IAM授权。

成员分为所有者、管理员、普通成员：

| 角色 | 可做什么 |
| --- | --- |
| 所有者 | 管理订单和邀请；调整非所有者成员角色、移除成员 |
| 管理员 | 管理订单；邀请普通成员，不可提权为所有者或管理所有者 |
| 普通成员 | 查看所属空间基础信息，不可读取余额、账单及他人邮箱 |
| 平台管理员 | 管理客户账号状态、租户测试开通、优惠券与审计；此身份不是企业业务管理员 |

邀请凭证24小时有效、一次性使用，并绑定受邀邮箱和空间。当前由管理者通过可信渠道转交，没有自动发送邮件。加入时再次核对空间状态、邀请发起者当前身份与席位；不要在公共群公开邀请凭证。付费会员到期后席位上限回到探索版，已有超额成员不会被自动移除，但新增成员受限。

账号停用会撤销会话；恢复账号也必须重新登录。成员管理与租户开通变更带版本号，过期提交不覆盖新状态。

## 订阅、余额与优惠

所有价格都是测试样例，不是正式报价：探索版免费，专业版99元/30天、团队版299元/30天。正式定价尚未确定；当前套餐在服务端PORTAL_PLANS维护，不提供在线改价后台。

- 余额和会员归属租户，不归属某次聊天或个人账号。
- 充值范围为测试1至100,000元。当前余额上限为测试1,000,000元。不可提现。
- 金额用整数分计算。前端只提交套餐或充值金额，不能提交总价、优惠金额或已支付状态。
- 先计算报价，再创建订单，核对当前订单后明确确认测试支付。支持模拟外部支付、测试余额购买会员。
- 订单30分钟过期。创建操作具备幂等键；重复支付只返回原结果，不重复扣款、入账或延期。
- 会员按30天测试周期，未到期的同套餐续费从原到期时间延长；已过期从当前时间开始。
- 当前不支持有效期内跨套餐升级/降级、按天补差或自动续费；没有未经说明的剩余时长损失。
- 测试会员续费折扣：专业版9.5折、团队版9折。优惠券支持固定减免或比例减免、最低订单金额、有效期、适用套餐、总次数。
- 会员折扣和优惠券择优，不叠加；充值不使用优惠券，每个租户每张券最多一次。优惠券未优于会员折扣时不消耗券名额。
- 待支付订单预占优惠券名额；取消或到期后释放。停用优惠券会取消与之关联的待支付订单，避免继续按停用优惠支付。
- 订单、余额流水、会员变更在同一个本地SQLite事务中提交。只展示测试回执，不生成微信/支付宝假回执。

会员记录不会解除数据权限、模型预算或审批限制。当前没有对方舟Token进行真实计量扣款，也没有向原有智脑执行面下发商业配额。

## 技术文档维护

独立接口契约：[产品门户OpenAPI](../../packages/api-contracts/product-portal.openapi.json)。它使用门户会话Cookie，不接受企业业务端的演示角色头；不要与原业务API契约混用。

公开文档的受控来源是[产品公开内容](../public/product-docs.json)，由官网显式打包，不向浏览器暴露整个docs目录。内部运维文档、私有配置、简历、测试原始资料与密钥不进入门户文档包。

当前使用Vue/Vite与Hash路由；主站有独立标题、描述和图标，文档支持标题/正文筛选。正式搜索引擎运营还需SSR/预渲染、稳定内容URL、站点地图、发布审核和内容版本管理。首页/产品页共用同一产品叙事，未建设独立CMS。

## 安全设计与限制

密码按随机盐+scrypt(N=2^17,r=8,p=1)保存。会话令牌数据库只保存摘要；客户端使用HttpOnly、SameSite=Strict Cookie，不写localStorage。CSRF令牌绑定会话，多标签读取不会轮换令牌造成互相失效。写请求还需匹配受信Origin、JSON类型和专用请求头。

API普通请求按已认证账号限制180次/分钟，匿名请求另按IP限制180次/分钟；保留每IP普通流量1200次/分钟防滥用上限。登录/注册每IP12次/分钟，密码计算并发上限2。不信任客户端租户头或代理IP头，当前不是分布式配额。请求正文最大8KB。示例容量上限：500账号、500租户、2000订单、1000优惠券、1000有效邀请、10000审计事件、8MB状态；达到上限拒绝写入，不悄悄删除财务记录。当前单聚合SQLite适合本机验证，不是规模化SaaS计费数据库。正式服务需要分表、迁移、索引、分页、分布式限流、恢复演练和隐私留存机制。

安全设计参考：[OWASP密码存储](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)、[OWASP CSRF防护](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html)。真实支付必须核验平台签名并核对订单和金额，不能相信浏览器跳转，参考[微信支付通知处理](https://pay.wechatpay.cn/doc/v3/merchant/4012791882)。这些资料是后续接入依据，不代表已经接通真实支付。
