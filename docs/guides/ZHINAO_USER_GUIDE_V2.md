2026-10-18结构咨询：在“知识资料”选定已发布模型图，明确勾选并新建“结构咨询会话”，即可在主聊天界面问具体对象的字段、主键和关联关系；“它”等续问只承接本会话上一次明确对象，支持明确纠正。顶部固定模型与版本，不能临时换模，版本改变需另建。该模式是确定性结构解释，不调用大模型、上传材料或查询业务事实，不执行/发布，不固定为全局长期记忆；普通业务任务不受影响。保存结果不确定时请刷新原任务核对，不自动重发。

2026-10-18模型结构入口：在“知识资料”中点击“读取授权模型目录”，再点击具体独立模型查看已发布关系图。仅显示当前企业身份被显式授权的模型，目录为空不表示应手动切换管理员角色。该功能只展示结构快照，不读取业务记录、不把所选模型应用到当前聊天，也不自动执行；详情版本变化或读取失败需重新读取目录。需要的运营准备、授权及旧发布记录处理见[模型实例指南](SEMANTIC_TENANT_INSTANCES.md)。

## 2. 三端入口

- 桌面 Web：浏览器打开智脑地址，适合无需安装的办公场景。
- Electron：安装“元域智脑”桌面应用，功能与 Web 一致并提供原生窗口。
- 移动端：适合告警查看、快速分析、待办与确认。

三端使用同一账号时，服务端任务、运行记录和证据链保持一致。

## 3. 多任务使用

1. 点击“新建任务”。
2. 为不同目标分别建任务，例如“8 月质量调查”“供应商补货”“市场投诉复盘”。
3. 在某个任务发送请求后，可以立即切到另一个任务继续工作。
4. 黄色跳动圆点表示该任务正在运行。
5. 任务右侧显示上下文占用和自动压缩次数。
6. 不再使用的任务可归档；正在运行或确认中的任务不能归档。

系统最多允许 8 个活动任务。达到上限时先归档一个任务。

## 4. 上下文与自动压缩

当前默认有效预算为 128K tokens/任务。右侧“任务上下文”显示占用比例：

- 低于 70%：保留当前安全消息。
- 达到 70%：自动把较早消息压缩为版本化摘要，保留最近 12 条消息。
- 压缩不会保存危险原文、密钥、内部思维链或权限变化前的旧答复。
- 如果角色或组织权限变化，历史智脑答复会隐藏，请在当前权限下重新查询。

## 5. 如何提出有效请求

推荐按“领域 + 对象 + 时间 + 目标”描述：

```text
请检查 8 月 20 日 PB-20260820-A 批次的质量风险，
列出证据、影响范围、责任人和需要我确认的动作。
```

不建议只说“查一下”“处理掉”“直接下单”。目标不明确时，智脑不会读取业务系统，而会提示需要补充的内容。

## 6. 错误或违规路径提示

智脑会显示“路径校验”卡片，包括：

- 不合理之处；
- 风险或规则原因；
- 合理化建议；
- 可复制修改的示例问法。

常见情况：

| 情况 | 正确做法 |
| --- | --- |
| 要求忽略规则、绕过审批 | 改为请求只读影响分析，或按流程申请权限 |
| 查询其他组织数据 | 限定本人/本组织，或让管理员配置数据域 |
| 目标模糊 | 补充领域、对象编号、时间和结果 |
| 当前角色能分析但不能执行 | 让具备完整权限的角色重新发起或走人工审批 |
| 上传材料不合规 | 使用支持的格式、控制在 4MB 内并先脱敏/扫描 |

## 7. 证据链

智脑答复下方可以展开：

1. 业务证据：来源系统、证据 ID、时间、分类、版本和内容哈希。
2. 执行计划：调用的受控工具及状态。
3. 完整证据链：输入校验、授权、检索、模型、计划、确认、执行和回执事件。

`TRACE` ID 是审计检索主键。哈希链显示“校验通过”表示事件顺序和内容未被单独篡改。重要决策仍应核对源系统。

## 8. 业务写入与确认

智脑分析不等于系统写入。出现“需要本人确认”卡片时：

1. 阅读影响说明、权限能力和审批路径。
2. 确认对象、数量、组织和时间。
3. 点击确认后，系统再次校验当前角色、会话、设备、runId 和一次性令牌。
4. 成功后只创建受控草稿或工作项，再进入审批。

令牌过期、角色撤销、设备变化或重复点击都会被拒绝。不要把确认链接或凭据转给他人。

## 9. 附件与语音

- 支持 JPEG、PNG、WEBP 和 PDF。
- 一次最多 3 个文件，单个不超过 4MB。
- 上传前删除密钥、令牌、身份证号、个人健康信息等不必要数据。
- 未完成内容扫描的材料不会进入模型上下文。
- 浏览器不支持语音识别时使用文字；生产环境建议接入企业私有 ASR。

## 10. 告警与虚拟电话

- P0：紧急，立即通知并按配置触发虚拟电话。
- P1：中风险，按策略通知和升级。
- P2：低风险，进入常规队列。

在告警卡片点击“交给智脑分析”，会在当前任务生成影响、建议、证据和需要确认的动作。电话按键回执只代表“已收到”，不能代替高风险审批。

租户管理员可在管理端“通知渠道 → 通知联系人”中维护联系人：从当前租户在役 IAM 人员名单选择用户，填写通知邮箱、脱敏电话和允许渠道，再发布新版本。没有发布权限的角色看不到候选人员目录。新租户默认没有联系人；未配置时告警会保留为待发送，不会使用 Demo 或其他企业的收件人。页面不会显示真实电话号码引用。

## 11. 安全注意事项

- 不在对话中粘贴 API Key、Token 或私钥。
- 不要求智脑冒充管理员或绕过审批。
- 权限不足时走权限申请，不借用他人账号。
- 对金额、批次放行、采购、质量和客户影响结论核对证据。
- 离开共享设备前退出登录。
- 发现旧权限数据仍可见时立即停止使用并联系安全管理员。

## 12. 常见问题

### 为什么模型支持 1.05M，但任务只显示 128K？

1.05M 是当前参考模型的硬窗口；128K 是产品默认有效预算。较小预算用于保证响应时间、成本和安全复核，且可按模型配置调整。

### 自动压缩会不会丢失重要信息？

系统保留任务目标、验证事实、run/trace 引用和最近消息。压缩摘要是确定性的并带版本/哈希；关键决策仍以证据链和源系统为准。

### 为什么历史答复突然隐藏？

角色或组织数据范围发生了变化。系统为防止旧权限数据继续暴露，会隐藏旧答复并要求按当前权限重新查询。

### Web、Electron、移动端功能一样吗？

核心任务、证据、确认、告警和待办协议一致。Electron 多原生窗口能力，移动端采用更紧凑的任务切换与底部导航。
