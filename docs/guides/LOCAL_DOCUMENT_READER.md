# 本地文档中心使用说明

文档中心用于阅读项目说明，不需要启动业务后端、智脑或语义服务。直接读取项目 `docs/` 和根目录 `README.md`，不另建文档副本，不修改原文件。

## 启动

在项目根目录运行（首次使用先执行 `npm install`）：

```powershell
npm run dev:docs
```

浏览器打开 <http://127.0.0.1:15200/>，终端保持运行。停止时在该终端按 `Ctrl+C`。端口被占用时，可以指定其他端口：

```powershell
npm run dev:docs -- --port=15201
```

## 查找与阅读

- 左侧按项目概览、技术架构、操作指南、模块说明、开发与验证、部署与运维、参考与交付等分类；分类来自现有文件夹，不是 AI 推断。
- 首页推荐项目状态、当前本体融合开发清单和图谱操作指南。历史归档默认隐藏，可勾选显示，或直接选择历史归档分类。
- 搜索支持标题、文件路径和可读文件正文。多个词以空格分开，结果需要包含所有词。`Ctrl+K` 可快速进入搜索框。
- 点击文档进入阅读页，右侧目录跳转章节；文档中的项目文档链接可直接跳转。窄屏自动隐藏右侧目录，以保留正文空间。
- 可按标题或文件修改时间排序。修改时间是文件时间，不代表文档结论仍然有效；阅读时以正文的日期和适用范围为准。
- 修改或新增原文件后点击“刷新文档”。目录缓存约一秒，无需重启服务。
- 阅读页提供原文件下载，Word、PDF、PowerPoint、Excel 等交付文件需要下载后用对应软件打开。

## 范围与安全边界

服务只监听本机 `127.0.0.1`，不发布到互联网、不上传文档、不调用大模型或业务 API。仅开放目录内允许的文档文件以及项目根目录 README；不开放源码、私有配置或任意磁盘路径。

Markdown 支持标题、表格、代码块和本地图片。原始 HTML 不执行，外部图片不自动加载。Mermaid 等图表代码目前按代码块展示，不自动绘图；PDF、Word 等二进制文件不做正文搜索。文本读取预算为单文件 2MB，下载预算为单文件 20MB，目录最多索引 2000 个支持的文件。

网页只提供阅读，不提供编辑、删除、权限管理或远程共享。不要将本地端口映射到公网。

## 验证

专项回归命令：

```powershell
npm run test:docs-reader
```

覆盖分类与隐藏文件过滤、Markdown 表格和章节锚点、内部链接、不可信 HTML 与越界链接、搜索与下载、跨站和非法 Host 拒绝、只读限制、目录链接过滤及新增文档刷新。本轮 7 项专项测试通过；页面视觉效果仍需在浏览器中检查。
