# 智脑与语义运营：对话及上下文使用说明

更新：2026-09-07。

## 两个端各做什么

智脑负责业务查询和日常工作协助。语义运营负责讨论数据字典、建立候选模型、校对与发布治理。咨询不需要先执行任务；系统也不能因为你提到“发布”就开始发布。

## 可以这样连续使用智脑

1. “我需要 ERP 库存报告，先用当前可访问的模拟数据，不生成文件。”
2. “列出三个最值得关注的问题。”
3. “第二个问题用两句话解释。”
4. “先不做报告，帮我排明天的工作：9点开会，11点前交周报，下午核对合同。”
5. “把周报截止时间改成10点半，其他安排不变。”

分析用到的数据应有来源，模拟数据应明确标注。没有读取到数据时，不能把一般建议当成公司实际情况。文件生成、业务草稿、审批等仍需查看执行计划并单独确认。

## 可以这样使用语义运营

先输入或上传数据字典，例如：

```text
只讨论方案，不保存、不发布。
采购订单 po_header：po_no 为主键，supplier_code，amount。
入库单 receipt：receipt_no 为主键，po_no 为采购订单外键，received_qty。
同一采购订单可多次入库。
请解释对象关系，以及金额如何避免重复统计。
```

接着可以问“采购订单的主键是什么？”或“为什么不能关联后直接汇总金额？”，不需要再次粘贴字典。

需要可视化候选时，再说“根据这份字典生成候选语义模型，仅展示提案供我审阅”。提案不是发布结果。检查表名、主键、字段、关系方向和基数，然后补全来源系统、类型及映射。未指定来源会显示 `UNASSIGNED` 或待校对，不能直接采纳；这表示材料尚不完整，不是平台已经验证了连接。

“建立模型，但不要发布”允许生成待审阅提案，不允许发布；“只讨论方案，不建模”只得到解释。质量经理等无发布权限角色，即使提出发布请求，也只会得到权限说明。

在候选编辑器中，可以修改“来源系统”（例如 `ERP / WMS`）和“数据来源”，并逐项核实字段类型、源字段及映射方式，再保存修订并重跑校验。不要为了通过校验随意填写来源；这里的编辑不会自动建立 ERP 连接。

## 状态怎么看

| 状态 | 含义 |
| --- | --- |
| 已回应 | 本轮对话已有回答，不表示业务已经执行 |
| 等待补充 | 缺少必要信息，任务尚未完成 |
| 等待确认 | 有待审阅计划；校验未通过时仍不能执行 |
| 权限不足 | 当前角色不能执行，未创建可执行计划 |
| 回答失败，可重试 | 本轮模型没有给出有效结果，不应当作完成 |
| 火山方舟理解 | 当前轮的语义理解使用了方舟；仍不等于工具已经执行 |

Semantica 启动后，可以点击语义端顶部“刷新服务状态”。“服务在线”和“模型已发布”是两回事，刷新不会发布模型。

## 记忆与材料边界

在同一任务中追问、更正或短暂切换话题，会使用该任务上下文。新任务默认隔离；需要跨任务使用的长期目标仍应主动固定。附件只使用通过扫描的有限文本摘录，不代表任意图片、录音或长文档都能完整理解。身份或权限变化后，旧受限内容不应继续带入回答。

本轮实测范围及限制见 [修复与验收记录](../development/AGENT_INTELLIGENCE_REPAIR_2026-09-07.md)。

多模态增量见 [附件使用及接入指南](AGENT_MULTIMODAL_GUIDE.md)：两端可查看“附件读取范围”，文件没读全或未能识别时应明确说明；附件续问使用有限摘录，不是全文永久记忆。真实模型文件/追问与扫描件测试记录见 [多模态专项](../development/AGENT_MULTIMODAL_ACCEPTANCE_2026-09-07.md)。
