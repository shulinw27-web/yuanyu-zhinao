# 图谱建模工作台操作指南

## 查看某个字段的变更影响

打开该字段所在的候选任务，输入 `检查字段删除影响“Supplier.risk_score”` 或 `检查字段变更影响“Supplier.risk_score”`。必须同时给出对象和字段编码，不能只写“风险分”让Agent猜测。

检查会列出其他字段、关系、治理规则和指标等配置中的引用/同名提及位置，候选、草稿、原提案分别标识。目标字段本身的声明不计为引用；位置中的数组编号保留原配置索引。报告不包含配置正文，不查询业务数据，也不改变审核凭证。

本轮修复了字段撤回漏查普通治理policies规则的问题。即使界面没有展示该规则，服务端也会拒绝撤回被引用字段。没有发现引用不代表主键或已有字段可以删除；普通撤回仍仅支持未映射的新候选字段。

本轮更新仅在本地，未提交或推送。

## 新对象因关系依赖不能撤回时

例如误新增Customer对象，并添加Supplier到Customer的serves声明关系：

1. 输入 `检查对象删除影响“Customer”`，查看哪些配置引用该对象。
2. 如果要取消的是本轮误新增关系，单独输入 `撤回候选关系“Supplier/serves/Customer”`。
3. 再输入 `检查对象删除影响“Customer”`，确认当前配置影响范围。
4. 符合新、未映射、无依赖条件后，输入 `撤回候选对象“Customer”`。

每一步单独发送，不合并成一条批量删除。关系必须用起点编码、关系编码、终点编码完整指定；只填写关系名称不会猜测目标。

原提案或草稿已有关系、标识确认生成关系、带主数据映射或有效期的关系不能这样撤回。其他关系或业务规则提及该关系时，也会拒绝，不自动移除依赖。撤回成功只修改候选，旧确认凭证失效；仍需重新审核，不影响业务记录。

## 修改前先看影响范围

打开待审核候选任务，输入 `检查对象删除影响“Supplier”` 或 `检查对象变更影响“Supplier”`。必须使用当前候选中的稳定对象编码，单独发送，不夹带删除、修改或发布要求。

Agent会检查该候选、原提案和当前草稿中的关系、字段、指标、规则、访问策略及其他支持的业务配置，显示位置，例如 `candidate · metrics.0.expression` 表示当前候选第一个指标的表达式提及该对象。candidate、draft、original分别代表候选、草稿和原提案。

结果只给位置和计数，不回传配置正文，不查询业务记录。同名文字也会计入，需人工判断是否真有依赖；重复范围中的位置不自动合并。对话最多显示20处，报告保留前100处并说明截断。超出扫描预算明确失败，不能据此认定“无依赖”。

检查不修改提案或确认凭证，不表示已有对象可以删除；模型变化后应基于新的修订重查。当前尚不扫描外部系统代码、实时数据或模型配置之外的消费者。

## 撤回误新增的对象

打开新增对象所在的待审任务，输入 `撤回候选对象“Customer”`。必须使用对象编码，单独提交，不与其他指令用分号混合。

只有尚未进入草稿、也不在原始提案中的新对象可以撤回；来源必须为UNASSIGNED，所有字段未映射。若已有关系、字段引用、业务规则或同名配置提及，Agent会拒绝并给出依赖类别，不会替你级联删除。最后一个对象不能撤回。

成功后候选修订号增加，旧确认凭证失效，需要重新审核。撤回不删除底层客户记录，不是发布版本回滚。被拒绝时先检查关系与业务配置，不能靠隐藏图中的连线绕过服务端校验。

## 通过Agent新增独立对象候选

先打开自己的待审提案，再在Agent工作台输入：

```text
新增对象“Customer”，名称“客户”，主键“customer_id”，类型“文本”，业务域“销售”，字段“name”，字段类型“文本”
```

对象编码最多32字符，主键和字段编码最多64字符，采用英文字母开头的字母、数字或下划线。主键仅支持文本或整数；普通字段支持文本、整数、数值、布尔、日期和日期时间，不能与主键重名。编码或名称与当前对象冲突时不会覆盖。

成功只新增待审核候选：独立元类型使用该对象自身编码，来源显示UNASSIGNED，字段来源映射为空且待确认。必须补齐来源和字段映射并通过现有校验，不能直接采纳或发布。不会读取或创建客户业务记录。

可用分号接续字段或关系新增，最多8条；任一指令失败整批不保存。修改后旧确认凭证失效，需要重新核对并确认。缺少信息或追加“发布模型”等混合操作会被明确拒绝；不支持已有对象的级联删除。

日期：2026-10-09。适用：元域智语模型总览、Agent 审核、知识资料及智脑授权读取结果。

2026-10-10增加只读多跳映射路径发现：在对照向导中选择起止对象、字段和1–4跳上限，自动查找已声明、字段连续且同UTC时点的路径。展示每跳对照版本、方向和原方案依据；多路径歧义不自动选择，循环、深度和预算限制明确提示。不会生成或执行查询，完整操作与边界见[主数据映射指南](ONTOLOGY_MASTER_DATA_MAPPING.md)。

## 本次编辑工作区

模型页的业务关系图、对象配置和关系修改共用同一份本次草稿。点击对象后选择“修改选中对象”，技术配置按需展开；点击连线可修改关系名称、基数和依据说明。保存、校验、模拟构建和登记操作始终可见，修改不会自动发布。

“撤销／重做”只恢复本次页面编辑，最多50步，并受历史内存预算限制，不是发布版本回滚。刷新、角色或服务端模型变化后清空历史。出现未保存修改时，校验及发布仍禁用；向 Agent 提问也要求先保存，避免旧修订解释新图。

校对问题可点击定位对象或关系。服务端部分结构校验返回字段和对象/关系目标，可直接跳转处理；有未保存修改时隐藏旧校验目标，无法确定目标的复杂错误只提供详情。“按关联自动布局”按关系方向排列，环路对象同层；只是视图变化，不改变业务关系。复杂关系的完整避让和领域折叠仍待完善。深化进度见[阶段计划](../development/ONTOLOGY_WORKSPACE_UPGRADE.md)。

## 看图和核对关系

进入“模型校对”，先查看业务对象关系图。点击对象看业务含义与来源，点击连线看基数、依据；字段与标识默认折叠。绿色、黄色和虚线红色分别表示新增、修改和删除，文字同时说明状态。修改关系时可查看修改前/后的基数和证据。

搜索名称、编码或系统；选择来源可缩小范围。选中对象后可只看它的邻居。箭头有方向，反方向无路径不代表没有任何业务联系，只说明模型未声明该方向。拖动不修改语义；“保存本次会话布局”先暂存布局，随后在“我的模型视图”点击保存，才会写入个人视图并生成跨刷新恢复链接。

模型超过100个对象时默认只显示前100个，可主动扩大到最多500个，或通过搜索定位范围外对象。大型模型优先搜索与邻居展开，不建议把所有字段一起展开。

Agent 任务中的图与总览共用组件。点击“向 Agent 提问”只将问题填入输入框；用户发送后才进入对话。未保存编辑不显示旧差异，需先保存修订并重跑校验，再确认采纳。审核采纳不是发布。

## 看底层系统如何关联

展开“跨系统来源与字段映射”，选择一个对象。图中显示系统、业务对象、映射字段与引用目标；节点详情说明源表/API、源字段、主键及映射状态。缺少资料时明确显示未登记或待核对。这里是模型的映射声明，不能证明 ERP/WMS 连接已通。

展开“用问题定位模型路径”，例如输入“采购订单与供应商有什么关系”。支持对象别名和指向该对象的业务术语；选中对象后可以问“它与生产批次有什么关系”。询问单个对象的含义可获得模型解释。同名或同别名目标使用编码区分，不会自动合并实体。数量、金额、库存等问题需要智脑的已发布只读计划及业务编号，不能用类型图的节点数回答。

## 从模板开始与格式导入

“从业务模板开始”有采购收货、生产质量、仓储履约和 OA 内部事务四类。先看候选关系和同名冲突，再带入 Agent 输入框。模板不会自动选择企业系统、猜测字段、覆盖对象或发布。按“建模上手路线”依次提交材料、核对关系、修订提案、校验、模拟构建和受控发布。

“行业 Mock 方案包”提供采购、生产、履约和入职四类合成材料，包含 API、数据字典、需求、样本分叉和验收问题。点击“将完整 Mock 材料交给 Agent 核对”交接原文；用户仍需核对来源、授权与建模提案，不能将示例当作真实企业数据。

字典为结构化JSON；包内 `suggestedReadPlan` 是只读分支统计候选，需要人工审阅、回放和发布，不带运行授权。开发验证可运行 `npm run test:ontology-industry`：4类材料解析到发布和智脑读取使用Mock连接器回归，不代表真实模型对话效果已验收。

“模型交换”提供平台结构包、中立 JSON-LD、Playground 参考 RDF/XML 子集和中立 Turtle 子集。平台结构包保留系统及字段映射声明，中立配置不带系统映射。字段类型、主键、单位、文本枚举和允许为空的说明注解可往返；不导出授权、凭据字段、业务实例或执行计划，不执行 OWL 推理。损失报告须人工查看，外部类缺少字段/主键时拒绝。文件上限240KB，禁止 DTD 和实体声明，不访问远程地址。原文和转换结果先预览，再显式交给 Agent；导入不直接写入模型。

Turtle 使用本地 N3 解析器，限定命名类、对象关系和平台结构注解，最多12000条语句、1000个主体。空白节点、集合、重复属性、身份冲突及不合法注解拒绝；未知谓词进入损失报告。IRI仅是标识，不会下载远程内容。这里不是通用OWL推理器，也不保证任意第三方本体完整保真。

## 将资料关联到业务对象或关系

在知识资料“查找依据”先检索，再到“资料与业务对象关联”。可以手动选择对象或关系，或“按明确名称查找候选”（不调用模型）。管理员启用资料模型策略后，可勾选同意将本次选定片段及目标目录发送到显示的提供方/模型，再点击“AI 分析已检索依据”。模型建议必须引用本次可读片段、选择当前模型目标，调用前后重新核验。未配置策略、服务不可用或目标编造会明确失败，不生成假AI建议。目标目录超过2700字符需缩小范围。建议不证明制度权威性，均不自动保存。

逐条核对片段和目标，选择关联含义，勾选确认后保存。对象版本、关系或原文发生变化时，旧关联提示重新核对；失效原文不继续展示。记录区可核验原文或撤回。关联仍按企业、主体、角色隔离，不会因为共享模型审核而自动向他人开放私有资料。

## 分享模型与查看智脑实例图

### 将模型审核指派到具体人员

在Agent工作台打开待确认的模型任务，“待审核语义模型”区域会显示当前承办人和指派修订。选择当前租户有语义端页面、草稿保存与审核权限的有效人员，再点“确认指派 / 转派”。首次指派可由有审核权限的人员操作；已指派后，只允许当前承办人或有审核权限的创建人转派、退回审核池。指派不是授权，不是模型采纳或发布。

指派与定向提醒在同一事务保存，旧确认凭证立即作废。非创建人的其他审核人员不再读取或确认该任务；创建人仍能跟踪自己的任务，但不能替代承办人确认。承办人失去权限后也不能审核。界面待办只计算审核池及分给当前人的任务，转派失败或修订冲突须刷新后重试。定向提醒不发送到钉钉或OA，只出现在现有平台通知中心。

选择对象后生成模型定位链接。链接只携带指纹与对象编码，不能绕过登录和权限。接收人的当前模型不匹配时拒绝定位，不自动加载历史版本。部署在本机的127.0.0.1链接只在本机有效；团队需使用同一已部署站点地址。

智脑完成已发布模型的授权读取后，回答可展开“本轮授权读取的业务实例关联图”。它展示实际记录编号、来源、版本及声明外键匹配，不是建模类型图。缺失数据不补造，不把关联当作根因或审批通过；预算超限会提示部分连线未展示。刷新、重新登录或恢复历史对话需重新查询，不把旧图当作当前授权。

实例图还列出已发布业务关系：快照内匹配、快照内无匹配、未声明引用、映射歧义、需要执行主数据映射。最后一种不会按相同字段值冒充对齐，也不通过同字段的底层外键连线绕过；依赖未执行映射的读取计划会在查询前拒绝。显式绑定版本化、确认的对照对象后，成功读取可显示“快照内已通过确认的主数据映射关联”。支持明确声明的正向或反向查询，反向对照必须唯一；无匹配不等于企业范围内不存在。递归转换与规则脚本不支持。配置与限制见[主数据映射指南](ONTOLOGY_MASTER_DATA_MAPPING.md)。

### 复杂关系图怎么查看

先点“按关联自动布局”，再按来源系统或所选对象的邻居缩小范围。“按来源系统缩小范围”提供对象数量和快捷按钮，多来源对象在各来源中分别计数；需要看跨系统路径时切回“全部来源”。这不是主数据合并或业务域折叠。

对象较多时点“来源分组总览”。每个对象按完整来源集合只归入一组，例如ERP/WMS多来源对象单独成组；未声明来源单列。组卡列出对象数及组内关系，组间箭头列出原始关系数，正反方向和待删除关系分开。这里只汇总当前筛选中的声明，不意味着系统接口已打通，也不推断影响或因果。

点“展开组内对象”看该组的原始模型图；点组间“查看原始关系”看指定方向的原始连线。页面会提示哪些关系被隐藏，可点“恢复当前筛选的全部关系”或“返回分组总览”。分组较多时按需加载更多，详细图仍最多展示500对象，完整路径需结合显示范围核对。总览不保存为业务对象或个人布局；外部对象/路径定位会退出分组视图。

并行、反向及自关联分别显示曲线。关系文字会避让节点和其他文字，拥挤时提示收起的文字数量，但不会删掉连线；点击连线、鼠标停留或用Tab选中后按Enter，可查看完整名称、基数和依据。拖动对象后会重新计算文字位置。图说明已声明结构或本轮授权快照，不证明根因和完整影响范围。

## 个人视图与只读嵌入

在关系图暂存布局后，展开“我的模型视图”，输入名称并保存；支持新建或以修订比较更新，最多20个。保存会生成个人授权链接，刷新同一链接可恢复。切换租户、用户或角色不能读取原身份视图，模型变更后旧视图返回冲突，需重新保存。这里只保留布局，没有历史模型浏览。

有模型审核权限时展示“团队模型视图”。同时有草稿保存权限的人员可以显式分享自己的已保存视图，形成不可变布局快照；其他本租户审核人员可读取并恢复布局，不能读取原个人视图。分享不包含知识库、业务记录、凭据或授权。模型指纹变化、权限撤销或分享撤回后拒绝恢复；仅分享者可凭修订号撤回。最多20个有效分享、100条日常记录，达到预算时拒绝新增。此功能不包含共享资料审批，也不是公开链接分享；模型审核逐人指派见前述工作台步骤。

“团队视图历史”按20条分页展示已撤回和归档的名称、修订与状态，不返回布局或原个人视图标识。原分享人可选择自己已撤回的记录，点击“归档我已撤回的记录”；事务将记录移入归档区，保留历史而非删除，并释放日常100条预算。未撤回、他人记录、旧修订或无当前权限都拒绝。归档区最多1000条，满额时明确拒绝，不自动清理。已撤回或归档记录不能直接恢复为有效分享，需要从当前个人视图重新显式分享。

“登录后只读嵌入链接”使用 `?embed=ontology#saved-model-view=UUID`，登录及模型权限核验后仅展示模型图，不提供编辑、发布、布局保存或Agent执行入口；不显示业务记录或原始资料。本机地址不能被其他电脑直接访问，跨站iframe、SSO及真实企业部署另行验收。

## 业务域与连续模型对话（2026-10-09）

2026-10-10追加字段操作：在待确认候选的同一任务中，可输入`将“Supplier.contact”的字段说明改为“供应商联系人”`，也可修改字段单位、类型、必填或文本枚举。目标必须是现有的唯一`对象编码.字段编码`。类型支持string/number/integer/boolean/date/datetime及对应中文名称；必填用“是/否”；文本枚举用逗号分隔，最多30个不重复值，`清空`撤销枚举或单位。主键类型和取消主键必填需走专门校对，不支持普通字段指令。

如果误增了新字段，可以输入`撤回候选字段“Supplier.risk_score”`。只允许撤回未映射、非主键、未进入当前草稿的新候选字段；已有或已映射字段不支持这条指令。系统检查其他字段的引用，以及关系、读取计划、状态机、指标、契约、质量规则、策略等配置中的引用/同名提及；有疑点或超预算就拒绝并提示核对，不把同名提及当作已证明依赖。完整服务端提案会再次复验，包括界面未展示的治理配置。

撤回只修订同一候选，重算Diff和校验并使旧确认失效，不修改当前草稿或底层数据。撤回新增的待映射字段后，只有其他检查也通过时才恢复可确认。任意字段删除、自动清理依赖及批量删除仍未开放。

### 一次提交多项候选修改

也可以明确新增一条类型关系：`新增关系“fulfillsOrder”，从“Supplier”到“PurchaseOrder”，名称“履约订单”，基数“一对多”，依据“采购制度描述供应商承担订单履约责任”`。

两端必须是本次候选中已有、唯一的对象；编码使用字母开头的字母/数字/下划线，最多48字符。名称最多60字符，依据最多100字符，基数支持一对一、一对多、多对一、多对多。关系总量最多40条，与现有草稿保存预算一致；同方向、同编码、同终点的重复关系拒绝，不覆盖旧定义。可在同一批中继续修改新关系的名称或基数。新边标记为`declared`：依据是用户陈述，不等于已复验的资料证据、实体等价或记录匹配。跨系统身份对应和主数据映射仍走专门校对流程。

在同一待确认任务里，用分号分隔最多8项明确修改、字段新增或关系新增，整条消息最多4000字符。例如：

`将“Supplier”的业务域改为“采购”；将“Supplier”的业务名称改为“采购供应商”；将“Supplier”的业务说明改为“负责供货；不是生产主体”`

引号内的分号属于说明文本，不会拆成指令。系统按顺序在临时候选中处理，全部合法才保存一次候选修订、重算Diff与校验并使旧确认失效；任意一项失败，整批不保存。同一目标属性重复修改会被拒绝，不能夹带审核或发布指令。支持先新增字段再修改其说明，但来源映射仍待确认，不能绕过发布门禁。撤回字段须单独提交，以复验完整依赖。这是明确指令能力，不代表支持任意自由文本批量建模。

新增字段示例：`给“Supplier”新增字段“risk_score”，类型“number”，说明“待确认风险分”`。说明可省略，类型必需；每对象最多80字段。新增字段是非主键、可选、`pending`来源映射，不猜测底层API字段、不生成计算表达式。映射补齐并重新校验之前，确认令牌及写入草稿均被阻断。改变单位只是标注，不换算业务数据。修改仍展示候选Diff、保留原任务并使旧确认令牌失效。

重复字段、未知目标、过期修订、附件混入、多指令夹带发布请求均不作为合法字段修改。标识确认生成的关系必须在专门校对流程修订；普通关系指令可用稳定三元组`Stock/storedAt/Warehouse`定位，不猜测同名关系。

对象表单可选填“业务域”，例如采购、仓储、生产；未填写显示未归类，不根据ERP/OA等来源猜测。点“业务域总览”查看各域对象及跨域关系，再下钻到原始对象。该属性不授予数据权限、不证明业务系统已接通。

连线遇到对象遮挡时尝试有限绕行；无法解决会提示，不承诺复杂图完全无交叉。看不清连线时展开“原始关系列表”，直接点击关系查看名称、基数和依据。

校验提供精确目标时，可定位读取计划或治理配置。高级配置编辑器只修改该项，空集合问题则编辑对应对象数组；可撤销。草稿变更或撤权后旧编辑不能应用。修改不是保存，需重新保存、校验、模拟构建和审核。

在模型页选择对象后向Agent提问，会清除旧任务选择并填入问题，不自动发送。后端校验当前模型指纹和对象，旧版本需重新进入模型页。Agent获得的是结构元数据，不是底层业务记录。

同一待确认候选可明确提出`将“Supplier”的业务域改为“采购”`，也支持业务名称、业务说明、关系名称、关系基数、关系依据。用唯一名称或编码定位；歧义、未知目标及过期修订会拒绝。修改沿用同一任务与候选，但使旧确认失效；仍需用户确认、保存和发布。任意自由文本改写或自动发布不在此能力范围。
